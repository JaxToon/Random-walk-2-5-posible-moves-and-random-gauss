# Random Walk Simulations

Simulations of particle random walks, written for a college course:

1. 1D walk with 2 possible moves
2. 1D walk with 3 possible moves
3. Discrete 2D walk with 5 possible moves: (0,-1), (0,1), (0,0), (-1,0), (1,0)
4. 2D walk with normally distributed steps, (x, y) + (εx, εy) with εx, εy ~ N(0, 1)

```bash
pip install matplotlib numpy
python random_walk.py
```
